③ 相關性結論

  • BVR ↔ VZ0：中度正相關（Spearman ≈ 0.38–0.40；Part 內 0.3–0.56）。09U、23U（35A/570mV）最強（≈0.5），15U、24U、22U 次之。WAT BVR fail 高的 Lot，CP VZ0 fail 也偏高（BVR(500uA) 前 10% Lot：VZ0 2.15% vs 其餘 1.19%）。
  • IR ↔ IR0 / DIR0：弱相關（ρ ≈ 0.2–0.3）。IR(18V)→IR0 僅 15U、24U 有 0.3 左右；IR(18V)→DIR0 在 09U、23U 較明顯（0.34–0.44）。4 月 bin 轉移後，單看 IR0 或 DIR0 會失真，建議看 IR0+DIR0 合併。
  • BVR(500uA) / 5mA / 10mA 彼此高度共線，相關性大致相同，代表 CP VZ0 對 BVR 低電流到高電流 fail 沒有明顯區分。
  • 相關 ≠ 因果：WAT 在前、CP 在後（約 2 週），且 Part / EPI / Station 彼此交錯，需搭配下頁分群解讀。

⑳ 改善建議

  1. 確認 CP 4 月初 IR0/DIR0 變更：查證當週 test program / limit / bin 定義變更紀錄；變更前後的趨勢比較改用 IR0+DIR0 合併，避免誤判改善或惡化。
  2. 15U / 13U 專案處理：IR 類與 BVR fail 皆高（環球晶 EPI），建議做 EPI 批次、wafer map（#1~#25）與 BVR/IR 參數分布比對，找出 edge / 特定 wafer 集中現象。
  3. WAT BVR 上升趨勢：對 BVR(500uA/5mA/10mA)、IR(18V) 建立月 / 週 SPC fail-rate 管制線；對 2026-06、2026-09 的上升時間點回查 EPI / BGBM lot、機台維護與量測條件。
  4. 50A 品項 VZ0 偏高（≈1.7% vs 35A 0.4%）：WAT BVR 無法解釋，建議檢查 CP VZ0 limit 與 guardband、探針 / contact（contact(6) bin）、大面積 die 的量測條件，並做 WAT-CP 量測電流條件對照。
  5. Station 匹配：3380P-ATE-2101 在 4 月後 IR0+DIR0 偏高，建議以同 Part 同 Lot 做 1003 vs 2101 correlation（含 repeat test），確認是否機台偏移。
  6. Vf(260mA) / VF0(10)（15U、2101）：回查 2026-06～07 的 15U Lot 與 2101 的 Vf 量測條件（探針、接觸電阻、溫度），確認 8 月回落的原因（維修 / 換 EPI / 調整），並將 Vf(260mA) 列為 15U 的 WAT 預警指標（超過約 5 fail / Lot 時，CP VF0 平均約 1.7%）。
  7. 15U / 13U 的 WAT 特有測項：IR(19.3V)、DBV、IR(19V) 是這兩個 Part 最大的 WAT fail 來源，建議將它們納入 SPC 與 WAT→CP（IR0）的相關性分析，並優先檢視這些測項的 limit 與 EPI 批次。
  8. 監控與模型：BVR→VZ0 相關性僅中度（ρ≈0.4），不宜單靠 WAT BVR 預測 CP VZ0；IR(22V) 目前無 fail，可評估放寬 / 改為監控參數值（Summary 內有量測值）以增加鑑別力。
